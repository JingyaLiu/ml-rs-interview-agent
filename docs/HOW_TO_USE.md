# How to use

## Daily

1. Open this repo as a Cursor workspace.
2. Start an **Agent** chat.
3. Ask in plain English (or `@` a skill):

| You say | Skill |
|---|---|
| What should I do tonight? | prep-planner |
| Coach me on LC 3 — no spoilers | leetcode-coach |
| Quiz me on attention shapes | cs336-coach |
| Draft STAR story 1 from these bullets… | star-coach |

4. Confirm the agent **edited a vault file** — that is the record.

## Force a coach

`@prep-planner` · `@leetcode-coach` · `@cs336-coach` · `@star-coach`

## Schedule

Edit `Learning-Vault/profile.md` once. Planners read it first.

## Optional loop

```text
/loop 1d Check Learning-Vault/plan/THIS_WEEK.md for today. Nudge me with one block.
```
