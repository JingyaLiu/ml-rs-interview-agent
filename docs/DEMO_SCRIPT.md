# Demo script (workshop / lightning talk)

Full stage script: intro → how others install → live profile/plan → one coach → ask the room.

## Skills map

| Goal | What to use |
|---|---|
| Profile / schedule | `Learning-Vault/profile.md` (file) + rule |
| Plan draft | skill `prep-planner` |
| LeetCode | skill `leetcode-coach` |
| CS336 | skill `cs336-coach` |
| STAR | skill `star-coach` |

## Live prompts

**Plan (must show):**
```text
Read Learning-Vault/profile.md. I only have 45 minutes tonight and I'm tired.
Use prep-planner: ONE block, update plan/THIS_WEEK.md with a checkbox.
```

**Pick one coach:**
```text
Use star-coach. Draft story 1 skeleton into behavioral/story-bank.md. Ask 2 clarifying questions first. Leave Result as TODO.
```

```text
Use leetcode-coach. LC longest substring unique chars — UNDERSTAND → RECOGNIZE → PLAN only. No code.
```

```text
Use cs336-coach. Multi-head attention shapes like a whiteboard interview. One quiz question after.
```

## How someone starts

```bash
git clone https://github.com/JingyaLiu/ml-rs-interview-agent.git
cd ml-rs-interview-agent
# Open in Cursor → edit Learning-Vault/profile.md → Agent: "What should I do tonight?"
```
