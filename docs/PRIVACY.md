# Privacy checklist (before publishing a fork)

This template ships **without** personal identity. If you fork publicly:

## Never commit

- Real full name + employer + LinkedIn (unless you want them public)
- Filled STAR stories with confidential metrics
- Company outreach trackers / recruiter emails
- Resume PDFs, offer letters, interview transcripts
- Internal project codenames that identify your employer

## Safe pattern

1. Keep a **private** vault (or `profile.local.md` gitignored).
2. Publish only skills/rules/hooks + empty templates.
3. Use relative lifts ("~X% offline NDCG") instead of unreleased absolute metrics in any shared notes.

## What was stripped from the public template

- Personal name, employer, LinkedIn
- Career timeline / school / citation details
- Specific company job IDs and outreach targets
- Personal calendar notes or talk scripts
